02 / PRINCIPLES

四句话先记住

🪵

别直接滚那条“带子”

髂胫束是筋膜，不是肌肉，硬压只会更疼。要滚的是股四头肌、臀部外侧和大腿内侧周边，把张力从两头松开。

🔥

48 小时后改热敷

热水袋或热毛巾 15–20 分钟，隔一层布。冰只在刚打完、有急性刺痛或发热时用，现在不需要。

🚶

别完全躺平

快走、慢骑车 20–30 分钟，让血流把代谢废物带走，比静养恢复快。疼感控制在 4/10 以内。

💪

臀中肌是根子

外侧疼的底层原因常是臀中肌撑不住，阔筋膜张肌和髂胫束替它干活。蚌式、侧卧抬腿、单腿臀桥要练起来。

    04 / MOVES

    7 个动作，照着做

    图解里：实线是身体位置，虚线是起始位置，青色箭头是发力/移动方向，粉色虚线圈是重点区域。每个动作下面都能单独计时。

    01 / ROLL外侧 · 前侧

    泡沫轴 · 股四头肌

    大腿前外侧一大片酸胀的主战场

    60–90 秒 / 侧1–2 轮疼感 ≤ 6/10
    1. 俯卧，泡沫轴横放大腿中段下方，双前臂撑地。
    2. 把体重压上去，沿大腿前侧从髋下方慢滚到膝盖上方。
    3. 碰到明显酸点停 20 秒，在原地小幅度碾，别憋气。
    4. 膝盖骨、髋骨和大腿内侧靠腹股沟的位置都别压。

    要点：慢比重有用。滚太快等于没滚；疼到咬牙说明压太狠了。

    常见错误：整个人重量一下砸上去、直接压膝盖、憋着气硬扛。

    02 / ROLL臀部外侧

    泡沫轴 · 臀部外侧

    臀中肌、阔筋膜张肌，别滚到腰

    45–60 秒 / 侧1–2 轮小范围移动
    1. 坐在泡沫轴上，右脚踝搭到左膝上，双手在身后撑地。
    2. 重心压向右侧臀部，前后小范围移动，找大转子后上方的酸点。
    3. 找到后停 20 秒，小幅度碾；换另一侧。
    4. 压的是臀部外侧，不是腰，也不是大腿外侧那条硬带子。

    要点：脚踝搭上去能增加压力。感觉是酸胀不是刺痛，腰部不能有放射感。

    常见错误：直接滚髂胫束（越滚越疼）、压在腰椎上、整个人重量一下砸下去。

    03 / STRETCH髋外侧 → 膝外侧

    交叉腿 · 体侧拉伸

    拉开髋外侧到膝外侧那一条线

    30 秒 × 2 组 / 侧呼吸放松不弹震
    1. 站立，疼痛侧腿交叉到另一条腿后方，双脚踩实。
    2. 同侧手臂举过头顶，向反方向侧弯。
    3. 骨盆保持正对前方，别撅臀、别转胯。
    4. 感到髋外侧到膝外侧一条线被拉开，停 30 秒，换侧。

    要点：拉伸感 5–6/10 就够。呼气时再侧弯一点，膝盖别锁死。

    常见错误：弯腰代偿、骨盆跟着转、憋气硬拉。

    04 / STRETCH膝盖内侧上方

    侧弓步 · 内收肌拉伸

    股内侧肌、内收肌群，膝盖内上方酸胀用这个

    30 秒 × 2 组 / 侧幅度渐进关节缝疼就停
    1. 双脚大幅分开站立，脚尖朝前，膝盖别内扣。
    2. 重心移向一侧，屈膝下蹲，另一条腿保持伸直。
    3. 双手扶在屈膝侧的膝盖或大腿上，直腿内侧有拉伸感。
    4. 停 30 秒，慢慢起身换侧；想加强可用手掌根轻推大腿内侧中段。

    要点：直腿脚尖朝前，别外八；下蹲不超过 90°；避开腹股沟和膝盖骨，不用硬轴猛压。

    常见错误：弓步太深、塌腰翘臀、把疼点压在膝盖内侧关节缝上。

    05 / STRENGTH臀中肌

    蚌式开合

    外侧疼的根子，先把臀中肌叫醒

    15–20 次 × 2–3 组 / 侧顶点停 1 秒慢放
    1. 侧卧，髋和膝各弯 90°，脚跟并拢，头枕在下侧手臂上。
    2. 骨盆保持垂直地面，别向后翻。
    3. 用臀部外侧发力，把上侧膝盖打开，像贝壳张开。
    4. 停 1 秒，慢慢放下，不砸、不借力。

    要点：感觉应该在臀部外侧，不是大腿前侧或腰。手放在屁股外侧，能摸到它在收紧。

    常见错误：身体后仰借力、两只脚分开、用腰转。

    06 / STRENGTH臀中肌

    侧卧直腿抬高

    练臀中肌的“稳”，不是抬得越高越好

    12–15 次 × 2–3 组 / 侧停 1 秒慢放
    1. 侧卧，身体成一条直线，下侧手臂垫头。
    2. 上侧腿伸直，脚尖朝前、略朝下。
    3. 慢慢抬到 30–40°，停 1 秒。
    4. 控制着放下，不碰下侧腿，再重复。

    要点：脚尖朝前，别朝上（不然变成练股四头）；骨盆别向后倒，身体别往前滚。

    常见错误：抬太高导致腰代偿、脚尖外旋、放下时自由落体。

    07 / STRENGTH臀大肌 + 臀中肌

    单腿臀桥

    让臀部接管大腿外侧的活

    8–10 次 × 2–3 组 / 侧顶点停 2 秒骨盆水平
    1. 仰卧，一侧脚踩地，另一条腿伸直抬起。
    2. 脚跟发力把髋顶起，肩—髋—膝成一条线。
    3. 顶点夹臀停 2 秒，骨盆保持水平。
    4. 慢慢落下，换另一侧。

    要点：用脚跟蹬地，不是用腰顶。顶起时腰不能反弓，感觉在屁股不在腰。

    常见错误：顶太高反弓腰、骨盆一边高一边低、用脚尖发力。

    05 / RED FLAGS

    这些情况别自己练

    出现任一条，去康复科 / 运动医学

    • 膝盖内侧是关节缝疼（不是肌肉），伴肿胀、卡顿、打软腿
    • 明显肿胀、淤青，或疼在某一个点越来越集中
    • 走路跛脚、腿发不上力、上下楼打软腿
    • 疼超过 1–2 周不减轻，或越来越重
    • 麻木，或疼往小腿、脚面放射
    • 同时腰痛，或咳嗽打喷嚏时腿疼加重

    什么时候能回去打球

    • 走路、上下楼、单腿站立都不疼
    • 按压酸点只剩轻微酸，不是刺痛
    • 先半场、低强度打 20 分钟试水
    • 第二天不反弹，再逐步加量

    回去打之前，先做 5 分钟动态热身（高抬腿、弓步走、侧向移动），别一上来就全场。
