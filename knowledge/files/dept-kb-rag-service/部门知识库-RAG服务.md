# 部门知识库 RAG 服务（接入说明）

> 来源：部门上线通知（2026-09-07）。服务部署于办公内网，检索准入材料、路演材料、产品材料等。

## 接入方式（Claude Code）

```json
"mcpServers": {
  "knowledge-base": {
    "type": "sse",
    "url": "http://192.168.100.148:8100/sse"
  }
}
```

## 使用要点

- 接入后 Agent 自动收到完整使用说明（工具决策树、分数解读、搜索技巧），无需额外培训
- 首次接入要求输入个人 API key（ask 工具用，key 谁调用谁付 token 费；search 工具免 key）
- 分数解读：>0.7 可直接引用；0.5-0.7 人工判断；0.3-0.5 弱相关；<0.3 基本不相关
- 覆盖范围：公司治理 / 风控 / 合规（含反洗钱）/ 投资管理（固收/权益/衍生品）/ 运营 / 信息科技 / 内控 / 公平交易与关联交易
