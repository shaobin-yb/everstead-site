01

五条纪律

按重要程度排序
01
止损止盈线：先写下来，再买进去重中之重
这条排在第一位，因为这一轮的难受，全部来自这里。
原话存档 「重中之重就是，止损止盈线。7 月份这波下跌之后，本来就可以止损，结果硬扛到现在越来越难受，甚至本金阶段，禀赋效应让自己更容易出现决策的问题。」 2026-10-27 · 语音转写，字词按语义理解，意思不动
EXECUTE · 执行条款
  • 买入前先写死三件事：止损价、目标价、仓位上限。写不出来 = 这笔不买。止损不是"心里有数"，是写下来的数字。
  • 止损线到点即执行，不设「再等等」的例外。7 月那次"本来可以止损"，例外只开了一次，代价是扛到现在。
  • 止盈同样预设，分批兑现。不追求卖在最高点——那是运气，不是能力。
  • 每天做一次「清仓测试」：如果今天是空仓，我还会在现价买它吗？答案是"不会" → 就该卖。成本价和决策无关，市场不知道你的成本。
02
空仓也是一种策略高优先级
钱空着有时间成本，但为了「不空着」而买入，成本更贵。
原话存档 「货币虽然有时间成本，但是空仓也是一种策略。空仓策略让自己更有定力，这个策略优先级也很高。」 2026-10-27 · 语音转写，字词按语义理解，意思不动
EXECUTE · 执行条款
  • 空仓是主动决策，不是"没仓位"的被动状态。没有符合纪律的机会时，空仓就是当下最优的仓位。
  • 接受货币的时间成本，换取定力。现金跑不赢风险资产是常态；为了不承担这个成本而强行入场，往往亏得更多。
  • 不为了「不空着」而找标的。手痒、怕踏空、怕钱闲着——这是强行买入的三个典型理由，都是情绪，不是逻辑。
  • 清仓后不急着回场，空仓期只观察、不动手。等「看准了」再买（纪律 05）；看不准就一直空着。
03
资金性质与持仓结构：先想清楚这是谁的钱
第一次用这么大的资金量、还是全家人的钱，去承受这么大的亏损。
原话存档 「这次带着全家人的资金去亏损了，第一次这么大资金量，迎来这么大资金量的亏损。配置一定要选好，持仓结构一直是必须要有的，不是眼睁睁看着快钱、热钱，自己没那个时点判断力。尤其不要除自己以外的资金去炒股。」 2026-10-27 · 语音转写，字词按语义理解，意思不动
EXECUTE · 执行条款
  • 资金按性质分级：家人的钱 = 不能亏的钱。只放债基 / 存款 / 货基，不进股市，不碰波动资产。
  • 持仓结构事先定义：核心仓 / 卫星仓比例、单票上限、单行业上限。结构是"必须一直有"的，不是行情好的时候才想。
  • 不追快钱、热钱。原话："自己没那个时点判断力"——承认这一点，就少亏一大半。
  • 除自己以外的资金，一律不进股市。赚了是应该，亏了是交代不清。这条没有例外。
04
杠杆资金：单独管、单独算、到线就撤
大帐乱管 = 没有细节 = 亏了都不知道亏在哪个账户。
原话存档 「杠杆资金设置好止盈线，杠杆资金单独管理，不要一团乱麻，大帐乱管理，没有具体的细节。杠杆资金，只要够一倍的收益率，立马收手撤离，债基稳收益。如果需要继续投资，只能拿出一半资金，然后止损是成本线。」 2026-10-27 · 语音转写，字词按语义理解，意思不动
EXECUTE · 执行条款
  • 杠杆资金独立账户、独立台账、独立纪律。不和自有资金混在一起算收益，亏了赚了都看得见来路。
  • 收益率到 +100%（一倍）→ 无条件清仓撤离，转债基。够一倍就收手，不恋战、不"再多赚点"。
  • 撤离后如再投资：只用一半资金，止损线 = 成本线。含义是：这部分钱不允许亏本金，碰成本线就走。
  • 债务到期日必须写进计划：到期前完成降杠杆。收益率和时间，谁先到听谁的（铁蛋补充，见建议 03）。
05
不做 T：把动作减到最少
做 T 的幻觉是"我能掌控市场"，实际多半变成半路加仓、山顶加仓。
原话存档 「个股的做 T 直接摒弃掉。这种 T 很多时候是自己觉得可以掌控市场，更多时候是半路加仓、山顶加仓，执行纪律也不好，以后不要做 T。看准了就买，需要就减仓，可以逐步减仓。如果断定今天低点、明天高开可以减仓，直接先卖掉手头的。」 2026-10-27 · 语音转写，字词按语义理解，意思不动
EXECUTE · 执行条款
  • 不做日内 T，不做"卖了再买回来"的差价。盘中临时决策 = 纪律最容易崩的时刻。
  • 买：看准了一次买或分批买，不追。
  • 卖：需要减仓就分批减，逐步兑现。减仓是仓位管理，不是猜点位。
  • 判断次日高开想减仓 → 直接先卖掉手头一部分。不赌次日，落袋为安。这是"先卖后不买"，不是 T。

03

铁蛋的建议

补强用 · 不代表老板原话
A1止损量化到数字，别只留在心里

建议三条线一起用：单票 -10%～-15%（按个股波动率定，波动大的取下限）、组合从高点回撤 -15% 硬止损、时间止损（买入逻辑 3 个月不兑现就撤）。三条线在买入前写进备忘录，触线只执行、不商量。

单票止损防个股，组合止损防"每只都没破线但加一起亏很多"，时间止损防"死扛等回本"。

A2三本账物理隔离

生活账户（家人的钱、生活备用金）／风险账户（自己的钱）／杠杆账户（借款）——分账户、分记录、不互相补。每月各算各的收益率，合并看总账。

"一团乱麻"的根不是记性差，是混账。混在一起，亏损就永远说不清是哪本账的问题。

A3杠杆目标加一条时间线

只设"一倍收益就撤"不够——债务有到期日。在日历上标出每笔借款的到期日，倒推降杠杆的时间表：收益率和到期日，谁先到听谁的。到期前没到一倍收益，也按计划降杠杆，不赌最后一把。

杠杆最大的风险不是亏，是"到期时必须卖"——被迫在坏时点平仓，主动权就没了。

A4减少决策次数 = 减少犯错次数

用条件单 / 价位提醒替代盯盘：止损价、止盈价提前挂好，盘中不看盘、不做临时决策。"直接先卖"这个方向是对的，把它变成默认动作——判断到了就执行，不和自己讨价还价。

每一轮亏损里，最贵的往往不是判断错，是盘中临时改主意。

A5亏损期三条禁令

① 不摊薄加仓（越跌越买 = 放大禀赋效应）；② 不换股追热点（亏了急着翻本，最容易追快钱热钱）；③ 情绪上头不做大额决策——难受的时候，"什么都不做"往往就是最优解。

亏损期的目标不是回本，是别让亏损扩大。

A6每笔交易留痕，月末只算一个分

买入记四项：逻辑 / 止损价 / 目标价 / 仓位理由；卖出记一项：触发了哪条纪律。月末不打收益率的分，只打纪律执行率的分（按计划做的笔数 ÷ 总笔数）。

收益率是市场给的，执行率是自己给的。执行率上去了，收益率是时间问题。

A7安全垫优先于一切收益

小七刚出生，现金安全垫是家庭的底线资产，不因行情波动挪用、不因"机会难得"进场。先保证生活不受投资影响，再谈收益。

投资的目的是让生活更稳，不是让生活跟着行情坐过山车。
